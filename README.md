# Broxy — Local Proxy Switcher

Простое расширение для Chrome/Edge (Manifest V3), которое маршрутизирует
**только выбранные сайты** через локальный прокси (HTTP / HTTPS / SOCKS5 /
SOCKS4). Весь остальной трафик идёт напрямую (`DIRECT`).

## Как это работает

Chrome не умеет задавать прокси для отдельной вкладки — настройка прокси
применяется ко всему браузеру. Поэтому Broxy использует **PAC-скрипт**:
для доменов из вашего списка возвращается ваш прокси, для остальных — `DIRECT`.

Это даёт два способа управления:

- **Список сайтов** — задаётся в настройках расширения.
- **Быстрый тумблер** — кнопка «Проксировать сайт» в попапе добавляет/убирает
  домен текущей вкладки, а общий переключатель включает/выключает прокси целиком.

## Установка (режим разработчика)

1. Откройте `chrome://extensions/`.
2. Включите **Developer mode** (правый верхний угол).
3. Нажмите **Load unpacked** и выберите папку этого проекта.
4. Иконка Broxy появится на панели.

## Использование

1. Откройте настройки (иконка → «Настройки и список сайтов»).
2. Укажите протокол, хост и порт вашего локального прокси
   (например `127.0.0.1:8080`).
3. Добавьте домены, которые нужно проксировать, и нажмите **Сохранить**.
4. Включите прокси переключателем в попапе.

Бейдж на иконке показывает количество сайтов в списке, когда прокси активен.

## Структура

```
manifest.json      — манифест MV3
background.js      — service worker, применяет PAC-скрипт через chrome.proxy
shared.js          — общая логика: хранилище и генерация PAC
popup/             — всплывающее окно (тумблер + быстрый тумблер сайта)
options/           — страница настроек (конфиг прокси + список сайтов)
```

## Заметки

- Настройки хранятся в `chrome.storage.local`.
- При выключении расширение очищает прокси (`chrome.proxy.settings.clear`),
  возвращая системные настройки.
- Авторизация прокси по логину/паролю PAC-скриптом не передаётся; при запросе
  кредов Chrome покажет стандартный диалог.
